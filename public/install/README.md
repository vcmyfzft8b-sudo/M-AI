# Install-guide screenshots

Drop real device screenshots here and they replace the drawn illustrations in
the "Dodaj na začetni zaslon" guide, with no code change:

    ios-1.png       Safari, share button on the bottom bar
    ios-2.png       the share sheet, scrolled to "Add to Home Screen"
    ios-3.png       the home screen with Memo on it

    android-1.png   Chrome, the three-dot menu top right
    android-2.png   the menu, showing "Install app"
    android-3.png   the home screen with Memo on it

The component tries the image first and falls back to its drawing when the file
is missing, so a partial set is fine — add them one at a time.

Take these yourself on a real device. Apple's and Google's interfaces are their
copyright and screenshots lifted from blogs or documentation are somebody
else's work; a capture you took on your own phone is yours to ship.

Portrait, roughly 3:4 or taller, and crop to the phone screen rather than
photographing the handset.
